# 02 — Go: protobuf + gRPC

## 1. Toolchain

| Componente | Pacote/Módulo |
|---|---|
| Mensagens | `google.golang.org/protobuf` |
| gRPC | `google.golang.org/grpc` |
| Plugin mensagens | `google.golang.org/protobuf/cmd/protoc-gen-go` |
| Plugin gRPC | `google.golang.org/grpc/cmd/protoc-gen-go-grpc` |
| Ferramentas | `buf` (recomendado) ou `protoc` |
| Gateway opcional | `github.com/grpc-ecosystem/grpc-gateway/v2` |
| Validação | `github.com/bufbuild/protovalidate-go` |

```bash
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
go mod init acme.com/catalog
```

## 2. Geração de código

### Com `buf` (recomendado)

```yaml
# buf.gen.yaml
version: v2
managed:
  enabled: true
  override:
    - file_option: go_package_prefix
      value: acme.com/catalog/gen
plugins:
  - local: protoc-gen-go
    out: gen
    opt: paths=source_relative
  - local: protoc-gen-go-grpc
    out: gen
    opt: paths=source_relative
```

```bash
buf generate
```

### Com `protoc`

```bash
protoc -I proto \
  --go_out=gen --go_opt=paths=source_relative \
  --go-grpc_out=gen --go-grpc_opt=paths=source_relative \
  proto/acme/catalog/v1/catalog.proto
```

O `option go_package` no `.proto` (ex.: `acme.com/catalog/gen/acme/catalog/v1;catalogv1`)
define o import path. O `go_package_prefix` do buf ajuda a evitar repetir.

## 3. Servidor

```go
package main

import (
	"context"
	"errors"
	"io"
	"log/slog"
	"net"
	"time"

	"google.golang.org/grpc"
	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/credentials"
	"google.golang.org/grpc/health"
	healthpb "google.golang.org/grpc/health/grpc_health_v1"
	"google.golang.org/grpc/reflection"
	"google.golang.org/grpc/status"

	pb "acme.com/catalog/gen/acme/catalog/v1"
)

type server struct {
	pb.UnimplementedCatalogServiceServer
}

func (s *server) GetProduct(ctx context.Context, req *pb.GetProductRequest) (*pb.Product, error) {
	if req.GetId() == "" {
		return nil, status.Error(codes.InvalidArgument, "id vazio")
	}
	return &pb.Product{
		Id:         req.GetId(),
		Name:       "Café",
		PriceMinor: 1999,
		Currency:   "BRL",
		Status:     pb.Status_STATUS_ACTIVE,
	}, nil
}

func (s *server) ListProducts(ctx context.Context, req *pb.ListProductsRequest) (*pb.ListProductsResponse, error) {
	// paginação com page_size/page_token
	return &pb.ListProductsResponse{NextPageToken: ""}, nil
}

func (s *server) WatchProducts(req *pb.WatchProductsRequest, stream pb.CatalogService_WatchProductsServer) error {
	for i := 0; i < 3; i++ {
		if err := stream.Send(&pb.Product{Id: "p"}); err != nil {
			return err
		}
		time.Sleep(100 * time.Millisecond)
	}
	return nil
}

func (s *server) UploadProducts(stream pb.CatalogService_UploadProductsServer) error {
	var accepted, rejected int32
	for {
		item, err := stream.Recv()
		if errors.Is(err, io.EOF) {
			return stream.SendAndClose(&pb.UploadSummary{Accepted: accepted, Rejected: rejected})
		}
		if err != nil {
			return err
		}
		if item.GetId() == "" {
			rejected++
		} else {
			accepted++
		}
	}
}

func main() {
	creds, err := credentials.NewServerTLSFromFile("server.crt", "server.key")
	if err != nil { slog.Error("tls", "err", err); return }

	grpcServer := grpc.NewServer(
		grpc.Creds(creds),
		grpc.MaxRecvMsgSize(4<<20),
		grpc.MaxSendMsgSize(4<<20),
		grpc.ChainUnaryInterceptor(unaryLogging, unaryAuth),
	)

	pb.RegisterCatalogServiceServer(grpcServer, &server{})

	// health + reflection
	hs := health.NewServer()
	hs.SetServingStatus("acme.catalog.v1.CatalogService", healthpb.HealthCheckResponse_SERVING)
	healthpb.RegisterHealthServer(grpcServer, hs)
	reflection.Register(grpcServer) // apenas em ambiente controlado

	lis, err := net.Listen("tcp", ":50051")
	if err != nil { slog.Error("listen", "err", err); return }
	slog.Info("serving", "addr", lis.Addr().String())
	if err := grpcServer.Serve(lis); err != nil {
		slog.Error("serve", "err", err)
	}
}
```

> `UnimplementedCatalogServiceServer` embutido garante forward-compatibility
> quando novos métodos forem adicionados.

## 4. Cliente

```go
package main

import (
	"context"
	"log/slog"
	"time"

	"google.golang.org/grpc"
	"google.golang.org/grpc/credentials/insecure"
	"google.golang.org/grpc/credentials"
	"google.golang.org/grpc/metadata"

	pb "acme.com/catalog/gen/acme/catalog/v1"
)

func main() {
	tlsCreds, _ := credentials.NewClientTLSFromFile("ca.crt", "")
	conn, err := grpc.NewClient("dns:///catalog.internal:50051",
		grpc.WithTransportCredentials(tlsCreds),
		grpc.WithDefaultCallOptions(
			grpc.MaxCallRecvMsgSize(4<<20),
			grpc.WaitForReady(true),
		),
	)
	if err != nil { slog.Error("dial", "err", err); return }
	defer conn.Close()

	client := pb.NewCatalogServiceClient(conn)
	ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
	defer cancel()
	ctx = metadata.AppendToOutgoingContext(ctx, "authorization", "Bearer "+token())

	resp, err := client.GetProduct(ctx, &pb.GetProductRequest{Id: "p-1"})
	if err != nil {
		st, _ := status.FromError(err)
		slog.Warn("rpc falhou", "code", st.Code(), "msg", st.Message())
		return
	}
	slog.Info("produto", "id", resp.GetId())
}
```

Use `grpc.NewClient` (substitui `grpc.DialContext`, que está obsoleto).

## 5. Interceptors

```go
func unaryLogging(ctx context.Context, req any, info *grpc.UnaryServerInfo,
	handler grpc.UnaryHandler) (any, error) {
	start := time.Now()
	resp, err := handler(ctx, req)
	slog.Info("grpc",
		"method", info.FullMethod,
		"code", status.Code(err).String(),
		"duration_ms", time.Since(start).Milliseconds(),
	)
	return resp, err
}

func unaryAuth(ctx context.Context, req any, info *grpc.UnaryServerInfo,
	handler grpc.UnaryHandler) (any, error) {
	md, ok := metadata.FromIncomingContext(ctx)
	if !ok { return nil, status.Error(codes.Unauthenticated, "sem metadata") }
	if len(md.Get("authorization")) == 0 {
		return nil, status.Error(codes.Unauthenticated, "sem credencial")
	}
	return handler(ctx, req)
}
```

Para tracing, use `otelgrpc`:

```go
import "go.opentelemetry.io/contrib/instrumentation/google.golang.org/grpc/otelgrpc"
grpc.NewServer(grpc.StatsHandler(otelgrpc.NewServerHandler()))
```

		{Field: "id", Description: "obrigatório"},
	},

## 7. Validação com protovalidate

```proto
import "buf/validate/validate.proto";
message GetProductRequest {
  string id = 1 [(buf.validate.field).string.uuid = true];
}
```

```go
import "github.com/bufbuild/protovalidate-go"

v, _ := protovalidate.New()
if err := v.Validate(req); err != nil {
	return nil, status.Error(codes.InvalidArgument, err.Error())
}
```

Ou como interceptor para validar todas as requisições.

## 8. Integração HTTP + gRPC no mesmo servidor

```go
import "github.com/soheilhy/cmux"

lis, _ := net.Listen("tcp", ":8080")
m := cmux.New(lis)
grpcL := m.MatchWithWriters(cmux.HTTP2MatchHeaderFieldSendSettings("content-type", "application/grpc"))
httpL := m.Match(cmux.Any())

go grpcServer.Serve(grpcL)
go httpServer.Serve(httpL)
m.Serve()
```

Alternativa: `h2c`/TLS ALPN, ou `grpc-gateway` para REST.

## 9. Segurança

- TLS/mTLS com `credentials.NewServerTLSFromFile` / `NewClientTLSFromFile`.
- `metadata` para tokens; nunca no payload.
- Limites `MaxRecvMsgSize`/`MaxSendMsgSize`.
- Interceptors de auth antes do handler.
- `reflection.Register` apenas em ambientes internos.
- Rate limiting e quotas por identidade (metadata).
- Valide entradas (`protovalidate`) e faixas de enum.

## 10. Logs e observabilidade

- `log/slog` estruturado; nunca logue `req`/`resp` crus.
- Registre `method`, `code`, `duration`, `peer`, `trace_id`.
- `otelgrpc` para spans; exporte OTLP.
- Métricas: `google.golang.org/grpc` tem stats handlers; use
  `otelgrpc`/Prometheus.
- Redação: campos sensíveis não devem ser logados; use IDs.

## 11. Performance

- Reutilize `*grpc.ClientConn` (uma por serviço alvo).
- `grpc.NewClient` é lazy; conexão é estabelecida na 1ª chamada.
- Buffers `proto.MarshalOptions{UseCachedSize: true}` quando aplicável.
- Evite reflection em caminho quente; use gencode.
- Streaming para grandes volumes; `MaxRecvMsgSize` alinhado.
- Compressão: `grpc.UseCompressor(gzip.Name)` (import `.../encoding/gzip`).
- Keepalive: `grpc.KeepaliveParams(...)` (cliente/servidor alinhados).
- `GOMAXPROCS`/pool de conexões conforme carga.

## 12. Testes

```go
import (
	"testing"
	"google.golang.org/grpc/test/bufconn"
	"google.golang.org/grpc"
	"google.golang.org/grpc/credentials/insecure"
)

func TestGetProduct(t *testing.T) {
	lis := bufconn.Listen(1 << 20)
	srv := grpc.NewServer()
	pb.RegisterCatalogServiceServer(srv, &server{})
	go srv.Serve(lis)
	defer srv.Stop()

	conn, _ := grpc.NewClient("passthrough:///bufnet",
		grpc.WithContextDialer(func(ctx context.Context, _ string) (net.Conn, error) {
			return lis.DialContext(ctx)
		}),
		grpc.WithTransportCredentials(insecure.NewCredentials()),
	)
	defer conn.Close()

	client := pb.NewCatalogServiceClient(conn)
	resp, err := client.GetProduct(context.Background(), &pb.GetProductRequest{Id: "p"})
	if err != nil { t.Fatal(err) }
	if resp.GetId() != "p" { t.Fatalf("got %q", resp.GetId()) }
}
```

- Teste round-trip com `proto.Marshal`/`proto.Unmarshal`.
- Teste erros e status codes.
- Teste streaming (client e server).
- `buf breaking` no CI.
- Fuzzing: `go test -fuzz=FuzzDecode`.

## 13. Pegadinhas

- `github.com/golang/protobuf` está **obsoleto** — use
  `google.golang.org/protobuf`.
- `protoc-gen-go` v1.20+ mudou a estrutura de campos; não use os getters
  auto-gerados antigos.
- `grpc.Dial`/`DialContext` obsoletos → `grpc.NewClient`.
- `go_package` ausente/incorreto quebra imports.
- `optional` em proto3 gera ponteiros (`*string`) — trate `nil`.
- Comparar `GetX()` com default não indica presença; use `field != nil`/`Has`.
- `io.EOF` no `Recv` de stream de cliente indica fim — não é erro.
- Canais sem deadline podem pendurar para sempre.
- Reflection precisa de `--include_imports`/descriptor se usar BSR.
